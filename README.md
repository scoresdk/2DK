# 2DK (TDK) - Two Development Kit

2DK is a SDK designed around zero-modification work for S+Core 7 devices. All code in this repo is designed to work out-of-the-box.
<br>
This is a rolling SDK, so expect breaking changes. Use the `stable` branch if you pull often.
<br>
It originally started as part of 7OS, before branching off into its own bit.
